# 轻跑

轻跑 2.0 是一款零依赖的个人 GPS 跑步日志 PWA。跑步路线、距离、时长、配速、公里分段、个人纪录和每周目标均保存在当前设备的 IndexedDB 中，不需要账户或后端服务。

线上地址：

```text
https://leberg-creat.github.io/qingpao/
```

## 本地运行

在 PowerShell 中执行：

```powershell
Set-Location 'D:\codex聊天\2026-11-03\wo\outputs\qingpao'
python -m http.server 4173 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:4173/
```

自动测试：

```text
http://127.0.0.1:4173/tests.html
```

## 部署与 iPhone 安装

1. 将整个 `qingpao` 目录上传到任意静态 HTTPS 托管服务，保持文件和目录结构不变。
2. 在 iPhone Safari 中打开部署后的 HTTPS 地址。
3. 点击 Safari 的分享按钮，选择“添加到主屏幕”。
4. 从主屏幕打开轻跑，点击“开始跑步”并允许使用精确位置。

iPhone 只在 HTTPS 安全地址下开放定位权限。通过局域网 HTTP 地址访问时，定位功能不可用。

## 数据备份

在“设置 > 数据管理”中可以导出 JSON 备份。导入时按记录 ID 增量合并，不会覆盖或删除本机已有记录；也可以选择同时恢复备份中的每周目标。

## 使用边界

- GPS 功能需要浏览器支持定位并授权精确位置。
- 跑步时请尽量保持轻跑处于前台；屏幕常亮会在浏览器支持时自动开启。
- iOS 可能暂停后台网页的定位。锁屏或切换应用造成的轨迹缺口不会补算，界面会在返回时提示中断。
- 数据只保存在当前浏览器或已安装 PWA 中。清除 Safari 网站数据、卸载 PWA 或更换设备前应先导出备份。
- 当前版本不包含云同步、手动补录、语音、震动和在线地图底图。
- 网页 PWA 无法保证锁屏后持续获取 GPS；真正的后台实时记录需要原生 iPhone 应用。
